# UHMC Business Department Digital Signage — ICS 418 Agile Project

> Team project for **ICS 418 – System Analysis and Design** at the University of Hawaiʻi Maui College (UHMC).

## Overview

The UHMC Business Department is receiving two 43" interactive touchscreen digital signage displays to be installed on the **1st and 2nd floors of Ka Lama**. This project's goal is to **propose and develop a working system** for these displays that serves students, faculty, staff, and visitors in the building.

The project follows an **Agile** approach: requirements are gathered from the customer, organized into a prioritized backlog, and delivered incrementally through short sprints with regular customer feedback.

## Requested Features

The Business Department would like the signage to support the following. These form the starting point of the product backlog and will be refined with the customer.

| # | Feature | Description |
| --- | --- | --- |
| 1 | **Program Promotion** | Showcase UHMC business programs: Business, Hospitality, Accounting, and ABIT |
| 2 | **Building Information** | Interactive directory with room numbers and locations |
| 3 | **UHMC Website Access** | Allow users to reach the UHMC website from the kiosk |
| 4 | **Job Opportunities** | Display business-related job openings |
| 5 | **Student Surveys** | Collect student feedback (e.g., *"What would you like to see/happen more on campus?"*) |
| 6 | **Events & Marketing** | Advertise events, special occasions, and department announcements |
| 7 | **Others (TBD)** | Additional features to be identified with the customer |

## Agile Process

- **Product Backlog** — Features above broken into user stories (e.g., *"As a student, I want to find a room number on the directory so I can get to class on time."*) and prioritized with the customer.
- **Sprints** — Short, time-boxed iterations, each producing a demonstrable increment.
- **Sprint Reviews** — Progress demonstrated to the customer for feedback.
- **Retrospectives** — Team reflects on what worked and what to improve.
- **Tracking** — Backlog and sprint progress tracked via GitHub Issues / Projects *(update if using another tool)*.
